# Склад 3D — как установить на Android

Приложение сделано как «веб-приложение» (PWA). Это обычная страница, которую Chrome
ставит на телефон как настоящее приложение: своя иконка, открывается без адресной строки,
работает без интернета. Данные хранятся только в телефоне.

Чтобы телефон мог его скачать, файлы нужно один раз положить в интернет.
Бесплатно и навсегда это делает GitHub Pages. Займёт 15 минут.

## Шаг 1. Распакуйте архив
На компьютере распакуйте `sklad.zip`. Внутри 7 файлов: index.html, manifest.webmanifest,
sw.js, три картинки icon-…png и эта инструкция.

## Шаг 2. Заведите аккаунт GitHub
1. Откройте https://github.com/signup
2. Почта, пароль, имя пользователя (латиницей, например `vladimir-print`). Запомните имя — оно будет в адресе приложения.
3. Подтвердите почту кодом из письма.

## Шаг 3. Создайте хранилище (репозиторий)
1. Справа вверху «+» → **New repository**.
2. Repository name: `sklad`
3. Отметьте **Public** (бесплатный Pages работает только с публичными; ваши данные туда не попадают, там только код).
4. Нажмите **Create repository**.

## Шаг 4. Загрузите файлы
1. На странице нового репозитория нажмите ссылку **uploading an existing file**.
2. Перетащите в окно все файлы из папки (не саму папку, а файлы внутри неё).
3. Внизу нажмите зелёную **Commit changes**.

## Шаг 5. Включите сайт
1. В репозитории вкладка **Settings** → слева **Pages**.
2. Source: **Deploy from a branch**. Branch: **main**, папка **/ (root)** → **Save**.
3. Подождите 1–2 минуты, обновите страницу. Сверху появится адрес вида
   `https://ВАШЕ-ИМЯ.github.io/sklad/`

## Шаг 6. Установите на телефон
1. На телефоне откройте этот адрес в **Chrome**.
2. Меню ⋮ (справа вверху) → **Установить приложение** (или «Добавить на главный экран» → «Установить»).
3. На экране появится иконка «Склад 3D». Дальше открывайте только через неё.

## Шаг 7. Первый запуск
1. Посмотрите примеры, нажмите «Удалить примеры».
2. Вкладка **Пластик** → «+» → тип, цвет, сколько граммов сейчас (полная катушка = 1000 г).
3. Вкладка **Детали** → саморезы, магниты, пакеты, этикетки.
4. Вкладка **Изделия** → «+» → название, артикул WB и **состав на 1 штуку**
   (граммы из Bambu Studio + детали).

## Как пользоваться каждый день
- Сняли партию с принтера → изделие → **Напечатал** → количество. Пластик и детали спишутся сами.
- Отправили на WB или покупателю → **Отгрузил**.
- Пришла катушка → пластик → **Пришло** → «+1 кат.».
- Пересчитали руками и не сошлось → **Пересчёт**, вводите фактическое число.
- Ошиблись → вкладка **Журнал** → «Отменить» у нужной записи.
- Кнопка «Пора пополнить» сверху показывает всё, что ниже минимума.

## Резервная копия — обязательно
Данные живут только в этом телефоне. Раз в неделю: вкладка **Копия** →
«Сохранить копию в файл» → отправьте файл себе в «Избранное» Telegram.
Новый телефон: установите приложение (шаг 6) → Копия → «Выбрать файл .json».

Не очищайте «данные сайта» Chrome для этого адреса — это сотрёт склад.

## Как обновить приложение
Если я пришлю новую версию: в репозитории Add file → Upload files → перетащите новый
index.html → Commit changes. На телефоне откройте приложение с интернетом, закройте
и откройте ещё раз. Данные сохранятся.

## Если хочется настоящий APK (необязательно)
Откройте https://www.pwabuilder.com, вставьте адрес из шага 5, нажмите Package for stores
→ Android → Generate. Получится APK для установки или для Google Play.
Для себя это не нужно: установка из Chrome работает так же.
